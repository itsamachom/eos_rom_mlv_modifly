ก่อนแบ่งปันรุ่นทดลอง เราเตรียมอะไรบ้าง

ปรับปรุง 5 พฤศจิกายน 2026 · บันทึกจากโครงการ

เราอยากแบ่งปันสิ่งที่ทำให้คนรักการถ่ายภาพได้ลองเรียนรู้ไปด้วยกัน แต่ก่อนชวนให้ติดตั้ง เราต้องอธิบายได้ว่าไฟล์นั้นมาจากไหน ตรวจอะไรแล้ว และยังมีอะไรที่ไม่ทราบ

คำว่า “รุ่นทดลอง” บอกอะไรเรา

v3r2 ยังเป็นรุ่นทดลองสำหรับ Canon EOS 600D ที่ใช้ Canon firmware 1.0.2 เท่านั้น ขณะนี้ยังไม่ได้ประกาศว่าพร้อมสำหรับผู้ใช้ทั่วไปหรือเป็นรุ่นเสถียร การมีไฟล์ใน repository ไม่ได้หมายความว่าการตรวจและการทดสอบเสร็จครบแล้ว

การทดสอบบนคอมพิวเตอร์เป็นจุดเริ่มต้น

เราสร้างบิลด์และตรวจการทำงานบางส่วนบนคอมพิวเตอร์แล้ว ผลเหล่านี้ช่วยตรวจปัญหาในโค้ดและการเชื่อมเมนู แต่ยังตอบไม่ได้ว่ากล้องจริงจะทำงานครบทุกส่วนอย่างไร

สำหรับ v3r2 เรายังไม่มีผลยืนยันการถ่ายภาพ วิดีโอ การเล่นเกม หรือการติดตั้งครั้งแรกบนฮาร์ดแวร์ เมื่อมีผลทดสอบเพิ่มเติม เราจะระบุรุ่นกล้อง เวอร์ชัน และสิ่งที่ทดสอบให้ชัด เพื่อให้ผู้อ่านประเมินข้อมูลได้ด้วยตัวเอง

ซอร์สและเครดิตเป็นส่วนหนึ่งของการเตรียมเผยแพร่

โครงการนี้ต่อยอดจากงานของผู้อื่นหลายส่วน เราจึงต้องเก็บเครดิตและใบอนุญาต พร้อมตรวจว่าซอร์สและข้อมูลการสร้างที่เตรียมไว้สอดคล้องกับไบนารีที่จะแจกหรือไม่

ขณะนี้พบซอร์ส candidate ของ dietlibc แล้ว และทดลองสร้างด้วยเครื่องมือหลายรุ่น แต่ยังยืนยันความสอดคล้องกับไลบรารีเดิมได้ไม่ครบ การตรวจนี้ยังไม่เปลี่ยนไบนารี v3r2 และยังไม่ปลดเงื่อนไขก่อนเผยแพร่ หากสนใจรายละเอียด สามารถอ่าน รายงานการตรวจซอร์สบน GitHub ได้

สิ่งที่เราจะอธิบายก่อนเปิดให้ดาวน์โหลด

หน้าเผยแพร่จะต้องบอกรุ่นกล้องและ Canon firmware ที่ใช้ได้ พร้อมซอร์ส วิธีสร้าง ใบอนุญาต เครดิต และ checksum สำหรับตรวจไฟล์ รวมถึงผลทดสอบจริง ปัญหาที่ทราบ และสิ่งที่ยังไม่ทดสอบ การเตรียมข้อมูลเหล่านี้ช่วยให้ผู้ใช้ตัดสินใจจากข้อเท็จจริงได้มากขึ้น

ช่วยโครงการได้ระหว่างที่เราตรวจต่อ

ระหว่างนี้ ยินดีรับข้อเสนอแนะเรื่องคำแปล ความชัดเจนของบทความ และหัวข้อที่คุณอยากเรียนรู้เพิ่มเติมครับ ยังไม่จำเป็นต้องติดตั้งบิลด์ทดลองเพื่อช่วยตรวจภาษา และเว็บไซต์ยังไม่เปิดรับเงินสนับสนุน

หากคุณมีผลทดสอบอยู่แล้ว สามารถแจ้งรุ่นกล้อง Canon firmware เวอร์ชันบิลด์ และอาการที่พบผ่าน Issue ได้ โดยไม่ต้องแนบข้อมูลส่วนตัวหรือ ROM ของ Canon เราจะนำข้อมูลที่ตรวจสอบได้มาอัปเดตสถานะทั้งสองภาษา

มีเรื่องที่อยากแบ่งปันกับเราไหม

ยินดีรับคำแนะนำเรื่องภาษาและหัวข้อที่อยากให้อธิบายเพิ่มเติมครับ

เสนอแนะผ่าน GitHub

โครงการรุ่นทดลอง · v3r2 ยังไม่พร้อมเผยแพร่สำหรับผู้ใช้ทั่วไป และยังมีการทดสอบบนกล้องกับการตรวจซอร์สที่ค้างอยู่ อ่านสถานะปัจจุบัน

อ่านต่อได้ที่นี่กล้องตัวเดิม กับจุดเริ่มต้นของเมนูภาษาไทย

โครงการอิสระจากประเทศไทย ต่อยอด Magic Lantern และใช้ Codex/LLM ช่วยพัฒนา โดยเก็บเครดิตและใบอนุญาตของผู้พัฒนาเดิม
