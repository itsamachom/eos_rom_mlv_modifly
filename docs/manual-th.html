Time-lapse

ภาพเมนูTime-lapseหน้าที่และวิธีใช้

สั่งถ่ายภาพซ้ำเป็นช่วงเวลา เพื่อนำภาพไปเรียงเป็นวิดีโอ Timelapse หรือบันทึกการเปลี่ยนแปลงระยะยาว

วิธีใช้: วางกล้องบนขาตั้ง ล็อกค่าแสงและโฟกัส ตั้งช่วงห่างและจำนวนภาพ แล้วเปิดใช้งานตามวิธีเริ่มที่เลือก

ตัวเลือกในหน้านี้

ช่วงห่างแต่ละภาพ (Take a pic every)
ช่วงเวลาระหว่างภาพ เลือกให้ยาวพอสำหรับเวลาเปิดรับแสงและเวลาบันทึกลงการ์ด หากกล้องยังไม่พร้อม ไม่ควรคาดว่าจะรักษาช่วงห่างได้ทุกภาพ
เงื่อนไขเริ่มถ่าย (Start trigger)
วิธีเริ่ม: Leave Menu เริ่มเมื่อออกจากเมนู; Half Shutter เริ่มเมื่อกดชัตเตอร์ครึ่งหนึ่ง; Take a Pic เริ่มหลังถ่ายภาพแรก

ตัวเลือกในหน้านี้

หน่วงก่อนเริ่ม (Start after)
เวลารอก่อนเริ่มชุดถ่าย ใช้เมื่ออยากให้กล้องเริ่มหลังจัดวางเสร็จ
หยุดหลังถ่ายครบ (Stop after)
หยุดเมื่อครบจำนวนภาพที่กำหนด ค่า OFF ไม่กำหนดจำนวนหยุดจากตัวเลือกนี้
  • ตัวอย่าง: ถ่ายทุก 5 วินาที จำนวน 120 ภาพ ใช้เวลาประมาณ 10 นาที; เวลาจริงขึ้นกับความพร้อมของกล้อง
  • ตรวจจำนวนภาพต่อครั้งใน ตั้งค่าการถ่ายภาพ ด้วย หากต้องการหนึ่งภาพต่อรอบให้ใช้ 1 (OFF)

ตั้งเวลาชัตเตอร์ B (Bulb Timer)

ภาพเมนูตั้งเวลาชัตเตอร์ B (Bulb Timer)หน้าที่และวิธีใช้

กำหนดเวลาเปิดรับแสงแบบ Bulb สำหรับการถ่ายนานกว่าค่าชัตเตอร์ปกติ

วิธีใช้: ใช้โหมด M/Bulb ตามการตั้งค่ากล้อง วางบนขาตั้ง กำหนดเวลา เปิดฟังก์ชัน แล้วเริ่มตามคำแนะนำบนจอ โดยต้นทางระบุการกดชัตเตอร์ครึ่งหนึ่งค้างประมาณ 1 วินาที

ตัวเลือกในหน้านี้

ระยะเวลาเปิดรับแสง (Exposure duration)
ระยะเวลาเปิดหน้าชัตเตอร์ เช่น 60 วินาที ไม่ใช่เวลารอก่อนถ่าย
หน้าจอขณะเปิดรับแสง (Display during exposure)
การแสดงจอระหว่างเปิดรับแสง: ไม่เปลี่ยนสถานะเดิม ปิดจอ หรือแสดงภาพก่อนหน้า หากตัวเลือกนั้นพร้อมใช้
  • การลดนอยส์จากการเปิดรับแสงนานของ Canon อาจทำให้ต้องรอเพิ่มหลังถ่าย ระยะห่างระหว่างภาพจึงอาจยาวกว่าระยะเปิดรับแสง

ถ่ายคร่อม (Bracketing)

ภาพเมนูถ่ายคร่อม (Bracketing)หน้าที่และวิธีใช้

ถ่ายหลายภาพโดยเปลี่ยนค่าแสง แฟลช หรือระยะชัด เพื่อเลือกภาพหรือรวมภาพภายหลัง

วิธีใช้: เลือกชนิดการคร่อม จำนวนภาพ และระยะ EV แล้วกดชัตเตอร์เพื่อเริ่มหนึ่งชุด

ตัวเลือกในหน้านี้

รูปแบบการคร่อมค่า (Bracket type)
เลือกสิ่งที่เปลี่ยน: ค่าแสง (TV, AV), ค่าแสงแฟลช หรือ DOF (Aperture) ป้ายบนจอควรอ่านร่วมกับหมายเหตุด้านล่าง
จำนวนภาพ (Frames)
จำนวนภาพในหนึ่งชุด; Autodetect ให้โปรแกรมคำนวณตามเงื่อนไขที่รองรับ ส่วน 2–12 คือจำนวนภาพที่กำหนดเอง

ตัวเลือกในหน้านี้

ระยะห่างค่าแสง EV (EV increment)
ความต่างค่าแสงระหว่างภาพ หน่วย EV ยิ่งมาก ภาพติดกันยิ่งสว่างต่างกัน
ลำดับการถ่าย (Sequence)
ลำดับคร่อม: 0 - -- ถ่ายจากค่าตั้งต้นไปมืด; 0 - + -- ++ สลับมืด/สว่าง; 0 + ++ ไปทางสว่าง โดย 0 คือค่าตั้งต้น ไม่ใช่จำนวนภาพศูนย์
หน่วงเวลา 2 วินาที (2-second delay)
หน่วงก่อนเริ่มชุดที่สั่งด้วยชัตเตอร์ ตัวเลือก OFF/Auto ใช้ตามเงื่อนไขของโปรแกรม ไม่ใช่ตัวกำหนดจำนวนภาพ

ตัวเลือกในหน้านี้

เลื่อนค่า ISO (ISO shifting)
เพิ่ม ISO เป็นตัวแปรคร่อม: OFF ไม่ใช้; Full พยายามใช้ ISO ก่อนแล้วจึงใช้ตัวแปรหลักเมื่อเกินช่วง; Half แบ่งผลระหว่าง ISO และตัวแปรหลัก
  • ป้ายไทย “ค่าแสง (TV, AV)” ตรงกับ Exposure (Tv,Ae) ในต้นทาง: โหมด M เปลี่ยนชัตเตอร์ โหมดอื่นเปลี่ยนค่าชดเชยแสง ไม่ได้หมายความว่าปรับรูรับแสงทุกโหมด การคร่อมรูรับแสงใช้ DOF (Aperture)
  • ปิด Canon AEB ก่อนใช้การคร่อมชุดนี้ เพื่อไม่ให้การตั้งค่าซ้อนกัน

ล็อคกระจกสะท้อน (Mirror Lockup)

ภาพเมนูล็อคกระจกสะท้อน (Mirror Lockup)หน้าที่และวิธีใช้

ยกกระจกสะท้อนล่วงหน้าเพื่อลดแรงสั่นก่อนเปิดรับแสง สำหรับการถ่ายภาพผ่านช่องมองภาพ

วิธีใช้: เลือกวิธีล็อคกระจกตามรูปแบบถ่าย และตั้งเวลาหน่วงสำหรับชุด Timelapse/ถ่ายคร่อมเมื่อใช้ฟังก์ชันเหล่านั้น

ตัวเลือกในหน้านี้

วิธีล็อคกระจก (MLU mode)
Always ON ใช้รูปแบบล็อคกระจกของ Canon ซึ่งโดยปกติกดชัตเตอร์ครั้งแรกยกกระจกและครั้งต่อไปถ่าย; Self-Timer ผูกการล็อคกระจกกับโหมดตั้งเวลาถ่ายของ Canon
สำหรับ Timelapse/ถ่ายคร่อม (Normal MLU Delay)
ป้ายไทย “สำหรับ Timelapse/ถ่ายคร่อม” คือเวลารอหลังยกกระจกก่อนถ่ายเมื่อโปรแกรมเรียกใช้ MLU เช่น Timelapse หรือถ่ายคร่อม มี 0.5, 0.75, 1, 2, 3, 4 และ 5 วินาที
  • ฟังก์ชันนี้ใช้ในโหมดภาพนิ่งนอก Live View และไม่มีตัวเลือกถือกล้องด้วยมือในบิลด์ 600D นี้
  • เวลาหน่วงนี้ไม่ใช่เวลาห่างระหว่างภาพ และไม่ใช่ตัวตั้งเวลาถ่าย 2/10 วินาทีของ Canon

ตั้งค่าแฟลช (Flash Tweaks)

ภาพเมนูตั้งค่าแฟลช (Flash Tweaks)หน้าที่และวิธีใช้

รวมการชดเชยแสงแฟลชและตัวช่วยใช้งานแฟลชบางรูปแบบ

วิธีใช้: ปรับเฉพาะตัวเลือกที่จำเป็นกับแฟลชที่ใช้อยู่ แล้วทดลองถ่ายและตรวจผลจริง

ตัวเลือกในหน้านี้

ชดเชยแสงแฟลช (Flash expo comp.)
ชดเชยความสว่างของแฟลช ช่วงตามโค้ดตั้งแต่ -10 EV ถึง +3 EV; เป็นค่าแสงแฟลช ไม่ใช่การชดเชยแสงฉากทั้งหมด
สลับใช้แฟลช (Flash / No flash)
สลับภาพที่ใช้แฟลชกับไม่ใช้แฟลช โดยภาพลำดับคี่ใช้แฟลชและภาพลำดับคู่ไม่ใช้
แฟลชเสริมใน LV (3rd p. flash LV)
วิธีช่วยให้แฟลชภายนอกบางชนิดยิงขณะใช้ Live View ปิดตัวเลือกนี้เมื่อไม่ได้ใช้ตามคำเตือนของต้นทาง
  • ผลขึ้นกับรุ่นแฟลช โหมด และการเชื่อมต่อ ไม่ควรตีความว่าแฟลชทุกตัวรองรับ

ตั้งค่าการถ่ายภาพ (Shoot Preferences)

ภาพเมนูตั้งค่าการถ่ายภาพ (Shoot Preferences)หน้าที่และวิธีใช้

ตั้งค่าที่หลายฟังก์ชันถ่ายภาพใช้ร่วมกัน เช่น จำนวนภาพต่อการสั่งถ่ายหนึ่งครั้งและการใช้ AF

วิธีใช้: ตรวจหน้านี้ก่อนทดสอบ Timelapse/ถ่ายคร่อม โดยเฉพาะเมื่อจำนวนภาพจริงต่างจากที่คาด

ตัวเลือกในหน้านี้

จำนวนภาพต่อชุด (Pics at once)
จำนวนภาพต่อหนึ่งเหตุการณ์สั่งถ่าย มี 1 (OFF) ถึง 9; ถ้าต้องการหนึ่งภาพต่อรอบให้ตั้ง 1 (OFF)
ใช้โฟกัสอัตโนมัติ (Use Autofocus)
ให้ฟังก์ชันถ่ายอัตโนมัติที่รองรับเรียก AF ก่อนถ่าย หากหาโฟกัสไม่ได้อาจไม่ถ่าย เหมาะกับเลนส์และโหมดที่รองรับ AF
สคริปต์หลังถ่าย (Post scripts)
สร้างข้อมูล/สคริปต์ช่วยรวมภาพจากการคร่อมและคร่อมโฟกัส: OFF, Enfuse, Align+Enfuse หรือ File List ไม่ได้หมายความว่ากล้องรวมภาพเสร็จให้ทันที

ตัวเลือกในหน้านี้

สคริปต์ถ่ายตามช่วงเวลา (Intervalometer Script)
สร้างสคริปต์จัดเรียงชุดภาพ Timelapse บนคอมพิวเตอร์: OFF, Bash, MS-DOS หรือ File List
จำลองการกดชัตเตอร์ (Snap Simulation)
จำลองการถ่ายเพื่อทดสอบ โดยส่งสัญญาณไฟ/เสียงแทนการถ่ายจริง หากต้องการไฟล์ภาพจริงให้ใช้ OFF

ถ่ายเมื่อเข้าโฟกัส (Trap Focus)

ภาพเมนูถ่ายเมื่อเข้าโฟกัส (Trap Focus)หน้าที่และวิธีใช้

สั่งถ่ายเมื่อวัตถุเข้าระยะโฟกัส ใช้กับการตั้งเลนส์เป็น MF ตามเงื่อนไขของระบบ

วิธีใช้: ตั้งระยะโฟกัสไว้ล่วงหน้า เลือก Hold AF button หรือ Continuous แล้วให้วัตถุเคลื่อนผ่านระนาบโฟกัส

  • OFF ปิดฟังก์ชัน; Hold AF button ทำงานขณะกดปุ่ม AF; Continuous ทำงานต่อเนื่องตามเงื่อนไขในโค้ด
  • นอก Live View ต้องมีเลนส์ที่สื่อสารกับกล้องได้ การตรวจโฟกัสขึ้นกับเลนส์และแสง จึงต้องทดลองก่อนใช้งานจริง

ถ่ายคร่อมโฟกัส (Focus Stacking)

ภาพเมนูถ่ายคร่อมโฟกัส (Focus Stacking)หน้าที่และวิธีใช้

ถ่ายหลายภาพโดยเลื่อนโฟกัส แล้วนำไปรวมเพิ่มระยะชัดบนคอมพิวเตอร์

วิธีใช้: ใช้ Live View กับเลนส์ AF ที่สั่งขยับได้ วางขาตั้ง ตั้งจำนวนภาพหน้า/หลังและระยะขยับ แล้วเรียก Run focus stack

ตัวเลือกในหน้านี้

เริ่มถ่ายคร่อมโฟกัส (Run focus stack)
เริ่มชุดถ่ายคร่อมโฟกัส กด MENU เพื่อขอหยุดตามคำแนะนำต้นทาง
ภาพระยะชัดด้านหน้า (Num. pics in front)
จำนวนภาพด้านหน้าของระยะโฟกัสปัจจุบัน ทิศจริงอาจกลับกันในเลนส์บางตัว
ภาพระยะชัดด้านหลัง (Num. pics behind)
จำนวนภาพด้านหลังของระยะโฟกัสปัจจุบัน ทิศจริงอาจกลับกันในเลนส์บางตัว

ตัวเลือกในหน้านี้

ระยะเลื่อนต่อภาพ (Focus steps / picture)
จำนวนคำสั่งขยับโฟกัสระหว่างภาพ ยิ่งมากจุดโฟกัสยิ่งห่าง แต่ระยะจริงไม่ใช่มิลลิเมตรคงที่
หน่วงรอแฟลช (Flash Delay)
เวลารอระหว่างช่วงถ่ายเพื่อให้แฟลชชาร์จกลับ
ใช้ช่วงย้ายโฟกัส (Copy rack focus range)
คัดลอกช่วงโฟกัสที่ตั้งสำหรับ Rack Focus มาใช้กำหนดชุด Focus Stacking
  • ภาพยังต้องนำไปรวมด้วยซอฟต์แวร์ภายนอก โปรแกรมไม่ได้ทำภาพชัดลึกสำเร็จบนกล้อง

ย้ายระยะโฟกัส (Rack Focus)

ภาพเมนูย้ายระยะโฟกัส (Rack Focus)หน้าที่และวิธีใช้

สั่งเลื่อนโฟกัสระหว่างตำแหน่งที่ตั้งไว้ เหมาะกับการเปลี่ยนจุดสนใจในวิดีโอ

วิธีใช้: ตั้งจุดโฟกัสต้นทางและปลายทางใน Live View ก่อน แล้วเรียกคำสั่ง Rack Focus

  • ต้นทางระบุ SET สำหรับสั่งเลื่อน และ PLAY สำหรับเลื่อนพร้อมเริ่มบันทึกเมื่อเรียกผ่านตัวควบคุมเดิม การทำงานของปุ่มใน Photo UI ขึ้นกับแถวคำสั่งที่เลือก
  • ใช้เลนส์ AF ที่กล้องสั่งโฟกัสได้ ความเร็วและความเรียบขึ้นกับเลนส์กับ Focus Settings

ควบคุมโฟกัส (Follow Focus)

ภาพเมนูควบคุมโฟกัส (Follow Focus)หน้าที่และวิธีใช้

ใช้ปุ่มทิศทางสั่งขยับโฟกัสแทนการหมุนวงแหวนบนเลนส์

วิธีใช้: เปิด Live View และใช้เลนส์ AF ที่รองรับ เปิดฟังก์ชันแล้วใช้ปุ่มตามคำแนะนำบนจอ

  • ขนาดและจังหวะขยับใช้ค่าจาก Focus Settings
  • ข้อกำหนดต้นทางคือ Live View/AF และไม่ใช้ Continuous AF; ระหว่างบันทึก MENU มีหน้าที่เกี่ยวกับการเก็บจุดโฟกัสในระบบเดิม จึงควรอ่านคำใบ้บนหน้าที่กำลังใช้อยู่

จุดสิ้นสุดโฟกัส (Focus End Point)

ภาพเมนูจุดสิ้นสุดโฟกัส (Focus End Point)หน้าที่และวิธีใช้

กำหนดตำแหน่งปลายทางสำหรับ Rack Focus ไม่ใช่การตั้งขอบเขต AF ของ Canon

วิธีใช้: เลื่อนเลนส์ไปยังระยะปลายทาง แล้วใช้ Q ในหน้าควบคุมเดิมเพื่อตั้งจุดตามคำแนะนำต้นทาง

  • คำใบ้เดิมระบุ Q ตั้งปลายทาง และ SET ร่วมกับซ้าย/ขวาสำหรับต้นทาง; Photo UI ใช้ Q เพื่อเปิดตัวแก้ไขเดิมก่อน
  • ต้องใช้ Live View กับเลนส์ AF ที่รองรับคำสั่งขยับ

ตั้งค่าโฟกัส (Focus Settings)

ภาพเมนูตั้งค่าโฟกัส (Focus Settings)หน้าที่และวิธีใช้

กำหนดวิธีส่งคำสั่งโฟกัสร่วมกันของ Follow Focus, Rack Focus และ Focus Stacking

วิธีใช้: เริ่มด้วยจังหวะขยับที่เลนส์ตอบสนองได้ แล้วค่อยปรับความเร็วจากภาพที่เห็นจริง

ตัวเลือกในหน้านี้

ระยะเลื่อนโฟกัส (Step Size)
ขนาดก้าวคำสั่งโฟกัส 1–3 เป็นระดับคำสั่งแบบ EOS Utility ไม่ใช่ระยะทางจริง
หน่วงระหว่างเลื่อน (Step Delay)
ช่วงรอระหว่างคำสั่งโฟกัสสองครั้ง เพิ่มค่านี้เมื่ออยากให้ส่งคำสั่งห่างขึ้น
รอให้เลื่อนเสร็จ (Step Wait)
รอสัญญาณยืนยันว่าเลนส์โฟกัสเสร็จก่อนส่งคำสั่งถัดไป

ตัวเลือกในหน้านี้

ทิศทางซ้าย/ขวา (Left/Right dir)
สลับทิศใกล้/ไกลของปุ่มซ้ายและขวา
ทิศทางขึ้น/ลง (Up/Down dir)
สลับทิศใกล้/ไกลของปุ่มขึ้นและลง
หน่วงก่อนเริ่ม (Start Delay)
หน่วงเป็นวินาทีก่อนเริ่มการขยับโฟกัส

ตั้งค่าระยะชัด (DOF Settings)

ภาพเมนูตั้งค่าระยะชัด (DOF Settings)หน้าที่และวิธีใช้

ตั้งค่าการคำนวณและแสดงระยะชัด ไม่ได้เปลี่ยนคุณสมบัติทางกายภาพของเลนส์

วิธีใช้: ใช้เพื่ออ่านข้อมูลประกอบการถ่าย โดยตรวจภาพขยายจริงร่วมด้วย

ตัวเลือกในหน้านี้

วงกลมความคลาด (Circle of Confusion)
เกณฑ์วงกลมความพร่าในการคำนวณระยะชัด ค่ายิ่งเข้มงวด ระยะที่ถือว่าชัดยิ่งแคบ ค่าต้นทางแนะนำ 19 สำหรับ APS-C
สูตรคำนวณระยะชัด (DOF formula)
Simple คิดจากความพร่าเพราะหลุดโฟกัส; Diffraction-aware พิจารณาผลเลี้ยวเบนของแสงร่วมด้วย
ข้อมูลระยะชัดใน LV (DOF info in LiveView)
เปิด/ปิดข้อมูลระยะชัดบริเวณข้อมูลระยะโฟกัสใน Live View

ตัวเลือกในหน้านี้

สมดุลแสงขาว (White Balance)

ปรับสมดุลน้ำเงิน/อำพัน (WBShift B/A)

ตัวคูณสีแดง (R multiplier)

ค่าประมาณขอบเขตสูงสุดของช่วงรับแสงที่เพิ่มขึ้น เป็นค่าอ่านอย่างเดียว ไม่ใช่ผลวัดภาพจริงทุกฉาก
ช่วงทับซ้อนโทนกลาง (Midtone overlapping)
ช่วงซ้อนทับของโทนกลางที่ได้ความละเอียดดีกว่า ส่วนไฮไลต์/เงามีข้อแลกเปลี่ยนด้านความละเอียดและ aliasing/moire

ETTR อัตโนมัติ (Auto ETTR)

ปรับค่าแสงเพื่อให้ข้อมูล RAW อยู่ทางขวาของฮิสโตแกรมโดยรักษาไฮไลต์ตามเป้าหมายที่ตั้ง

วิธีใช้: ต้องโหลด ettr.mo เลือกวิธีเรียกทำงาน กำหนดชัตเตอร์ช้าที่สุดและเผื่อไฮไลต์ แล้วตรวจไฟล์ RAW

เงื่อนไขเริ่มทำงาน (Trigger mode)
Always ON ปรับตามจังหวะที่รองรับ; Auto Snap อาจสั่งภาพเพิ่มหลังวัด; Press SET และ HalfS DblClick เรียกจากปุ่มเมื่อฮาร์ดแวร์/โหมดรองรับ ไม่ใช่ทุกตัวเลือกจะใช้ได้ใน Live View ทุกกล้อง
ชัตเตอร์ช้าที่สุด (Slowest shutter)
ชัตเตอร์ช้าที่สุดที่ยอมให้ระบบเลือก ป้องกันการลากเวลารับแสงเกินความต้องการ
ค่าแสงเป้าหมาย (Exposure target)
เป้าหมายไฮไลต์ ต้นทางแนะนำเผื่อประมาณ -0.5 หรือ -1 EV จากจุดอ้างอิงของระบบ

ภาพเดิมแสดงว่ายังไม่โหลดโมดูล รายการด้านล่างอธิบายจากโค้ดโมดูล ไม่ใช่ตัวเลือกที่เห็นในภาพนี้

สัดส่วนแสงจ้าที่ยอมข้าม (Highlight ignore)
สัดส่วนพิกเซลสว่างที่ยอมให้เกินเป้าหมาย เช่น จุดสะท้อนเล็ก ๆ
ยอมให้แสงล้น (Allow clipping)
กำหนดว่าจะยอมให้ช่องสีใดล้นค่าได้: ไม่ยอม, ช่องเขียว หรือช่องใดก็ได้
SNR โทนกลาง (Midtone SNR limit)
จำกัดการลดแสงเมื่อสัญญาณต่อสัญญาณรบกวนของพื้นที่โทนกลางต่ำกว่าเกณฑ์ อาจแลกกับไฮไลต์ล้นมากขึ้น

ภาพเดิมแสดงว่ายังไม่โหลดโมดูล รายการด้านล่างอธิบายจากโค้ดโมดูล ไม่ใช่ตัวเลือกที่เห็นในภาพนี้

เกณฑ์สัญญาณส่วนมืด (Shadow SNR limit)
เกณฑ์ลักษณะเดียวกันสำหรับบริเวณเงา
เชื่อมชัตเตอร์ Canon (Link to Canon shutter)
เชื่อมการกำหนดชัตเตอร์ช้าที่สุดกับการปรับชัตเตอร์จาก Canon ตามการรองรับของโมดูล
เชื่อมกับ Dual ISO (Link to Dual ISO)
ยอมให้ ETTR ปรับหรือปิด Dual ISO เมื่อไม่จำเป็น เพื่อให้ได้เกณฑ์โทนกลางและเงาที่ตั้งไว้

ตัวเลือกเมื่อโหลดโมดูลแล้ว

ภาพเดิมแสดงว่ายังไม่โหลดโมดูล รายการด้านล่างอธิบายจากโค้ดโมดูล ไม่ใช่ตัวเลือกที่เห็นในภาพนี้

แสดงบริเวณวัดแสง (Show metered areas)
แสดงพื้นที่ที่ใช้วัดส่วนสว่าง โทนกลาง และเงา

แสดงข้อมูลตรวจสอบ (Show debug info)

Focus Peaking

ภาพเมนูFocus Peakingหน้าที่และวิธีใช้

ทำเครื่องหมายบริเวณที่ระบบเห็นว่ามีรายละเอียดคม เพื่อช่วยหมุนโฟกัส

วิธีใช้: เปิดตัวช่วยแสดงภาพ แล้วปรับความไวให้เห็นรายละเอียดสำคัญโดยไม่ขึ้นเครื่องหมายทั่วจอ

เกณฑ์จุดชัด (Threshold)
สัดส่วนพิกเซลที่ระบบนับว่าอยู่ในโฟกัส เป็นความไวของตัวช่วย ไม่ใช่ค่าความคมไฟล์

ตัวเลือกในหน้านี้

สี (Color)
สีคงที่หรือการไล่สีตาม Global Focus/Local Focus
แสดงภาพขาวดำ (Grayscale image)
แสดงภาพ Live View เป็นขาวดำเพื่อให้สี Peaking เห็นง่าย
  • Peaking เป็นตัวช่วยประเมิน ไม่ใช่การรับรองว่าโฟกัสตรงทุกครั้ง ตรวจภาพขยายร่วมด้วย

QScale

โมดูลเสริม (Modules)

ภาพเมนูโมดูลเสริม (Modules)หน้าที่และวิธีใช้

เปิดหน้ารายการโมดูลเสริมของ Magic Lantern เพื่อเลือกโหลดความสามารถเพิ่มเติม

วิธีใช้: เลือกเฉพาะโมดูลที่ต้องใช้ แล้วออกจากเมนู ปิดกล้องตามปกติ รอไฟการ์ดดับ และเปิดใหม่ จากนั้นตรวจสถานะ OK

  • ใช้ไฟล์ .mo และ 600D_102.sym จากแพ็กเดียวกับ autoexec.bin
  • OFF คือยังไม่เปิด; ???/Err/FileErr ไม่ใช่สถานะสำเร็จ ให้เก็บข้อความปัญหาเพื่อตรวจต่อ
  • รายชื่อจริงขึ้นกับไฟล์ใน ML/modules/ คู่มือนี้ไม่ได้สมมุติว่าโมดูลทุกตัวถูกโหลดแล้ว

สคริปต์ (Scripts)

ภาพเมนูสคริปต์ (Scripts)หน้าที่และวิธีใช้

เปิดเมนูสคริปต์ที่โมดูล Lua ลงทะเบียนไว้

วิธีใช้: โหลด lua ตรวจสถานะ OK แล้วเข้ารายการสคริปต์ที่ต้องการ เลือก Run Script เพื่อรันครั้งเดียว

  • Autorun ใช้ให้สคริปต์เริ่มตอนบูต จึงไม่จำเป็นสำหรับการเปิดเกมชั่วคราว
  • รายการที่เห็นขึ้นกับไฟล์ใน ML/scripts/ และผลการโหลด Lua

ตัวอย่างการตั้งค่า

Timelapse ครั้งแรก

  1. ตั้งกล้องบนขาตั้ง ล็อกค่าแสง/โฟกัสให้เหมาะสม
  2. S → ตั้งค่าการถ่ายภาพ → จำนวนภาพต่อครั้ง ใช้ 1 (OFF) และปิด Snap Simulation
  3. S → Time-lapse ตั้งทุก 5 วินาที หยุดหลัง 120 ภาพ แล้วเลือกวิธีเริ่มที่สะดวก
  4. ตรวจภาพช่วงสั้นก่อนปล่อยถ่ายยาว และเว้นช่วงให้กล้องเปิดรับแสง/บันทึกทัน

ถ่ายคร่อมค่าแสง

  1. ปิด Canon AEB ก่อน
  2. S → ถ่ายคร่อม เลือกชนิดคร่อมค่าแสง จำนวน 3 ภาพ และความต่าง 1 EV เป็นจุดเริ่มทดลอง
  3. เลือก Sequence ที่ต้องการ เช่น 0 - + -- ++; จำนวนภาพยังขึ้นกับ Frames
  4. ถ่ายหนึ่งชุดแล้วตรวจภาพทั้งสามบนคอมพิวเตอร์ ก่อนเพิ่มระยะ EV หรือจำนวนภาพ

ใช้ตัวช่วยโฟกัสมือหมุน

  1. เปิด Live View และ O → เปิดตัวช่วยแสดงภาพ
  2. เปิด Focus Peaking เพื่อเห็นบริเวณคม แล้วใช้ Magic Zoom ตรวจซ้ำ
  3. ภาพที่เห็นบนจอเป็นตัวช่วย ไม่ได้เพิ่มรายละเอียดหรือซูมเลนส์ในไฟล์ภาพ

เมื่อผลไม่เป็นอย่างที่คาด

ถ่ายหลายภาพทั้งที่กดครั้งเดียว
ตรวจจำนวนภาพต่อครั้งใน Shoot Preferences, Frames ในถ่ายคร่อม และจำนวนภาพของโหมดตั้งเวลาถ่าย Canon ตัวนับ 2/10 วินาทีบอกเวลาเริ่ม ไม่ใช่จำนวนภาพเสมอไป
เปิด Zebra/Peaking แล้วไม่เห็น
ตรวจ Global Draw, สถานะ Live View, ตัวเลือกซ่อนระหว่างบันทึก และเงื่อนไขของตัวช่วยนั้น
Dual ISO / Auto ETTR / เกมยังใช้งานไม่ได้
ตรวจไฟล์โมดูล เปิดใน Modules แล้วรีสตาร์ตตามปกติ ต้องเห็น OK ก่อน สำหรับ Pong/Sokoban ใช้ lua ไม่ใช่โมดูลชื่อเกม
จำนวนชัตเตอร์ไม่ขึ้น
เป็นข้อมูลอ่านอย่างเดียว หากระบบอ่านจาก Canon ไม่สำเร็จจะไม่สร้างตัวเลขขึ้นมา เก็บภาพอาการและรุ่นที่ใช้เพื่อแจ้งปัญหา
เมนูเป็นอังกฤษบางส่วน
ภาษาไทยใช้กับ Photo UI และวลีที่มีในชุดฟอนต์ หน้า Classic คำเตือนจากโมดูล หรือข้อความที่ยังไม่มีคำแปลอาจยังเป็นอังกฤษ

คำศัพท์

Tv
ค่า APEX ที่เกี่ยวกับเวลารับแสง/ชัตเตอร์
Av
ค่า APEX ที่เกี่ยวกับรูรับแสง
Ae / AE compensation
การชดเชยแสงอัตโนมัติ ไม่ใช่คำเดียวกับ Av
EV
หน่วยความต่างค่าแสง 1 EV ต่างประมาณหนึ่งสต็อป
MLU
Mirror Lock-Up: ยกและล็อคกระจกสะท้อนก่อนถ่าย
DOF
Depth of Field: ระยะชัด
ETTR
Expose To The Right: จัดค่าแสงให้ข้อมูล RAW เข้าใกล้ด้านสว่างโดยคุมไฮไลต์
CBR / VBR
วิธีควบคุมอัตราข้อมูลวิดีโอ; CBR ของเมนูนี้ใช้ตัวคูณเทียบค่าปกติ ส่วน VBR ใช้ QScale
SNR
อัตราส่วนสัญญาณต่อสัญญาณรบกวน
Live View
การแสดงภาพจากเซนเซอร์บนจอแทนการมองผ่านช่องมองภาพ
