What we prepare before sharing an experimental release

Updated 5 November 2026 · Project notes

We would like fellow photographers to explore what we are making. Before inviting anyone to install it, we need to explain where the files come from, what we have checked, and what remains unknown.

What “experimental” means here

v3r2 is still experimental and targets only the Canon EOS 600D running Canon firmware 1.0.2. We have not announced it as stable or ready for general use. A file being present in the repository does not mean that all review and testing is complete.

Computer testing is a starting point

We have built the software and checked parts of it on a computer. Those checks help us find code problems and inspect menu connections, but they cannot tell us how every part will behave on a real camera.

For v3r2, photography, video, gameplay and first-time installation have not yet been verified on hardware. When further results are available, we will record the camera model, build version and tested behavior so readers can assess the evidence for themselves.

Source and credits belong in release preparation

This project builds on many other people’s work. We need to preserve their credits and license notices, and check that the source and build information we provide correspond to the binaries we intend to distribute.

We have found a dietlibc source candidate and tried building it with several toolchains. Its correspondence with the inherited library has not been fully established. This audit has not changed the v3r2 binaries or cleared the release requirement. You can read the source audit on GitHub for the technical details.

What readers should find before a download

A release page needs to identify the supported camera and Canon firmware, and include source, build instructions, licenses, credits and checksums for verifying the files. It also needs actual test results, known problems and a clear account of what has not been tested. These details help users make an informed decision.

Ways to help while the review continues

Suggestions about translations, clearer articles and topics you would like to learn about are welcome. You do not need to install an experimental build to help us review the wording. The website is not accepting financial contributions at this stage.

If you already have test results, you can share the camera model, Canon firmware, build version and observed behavior in an issue. Please leave out personal information and Canon ROM dumps. We will use verified information to update the status in both languages.

Something you would like to share?

Ideas for clearer wording and topics you would like us to write about are welcome.
