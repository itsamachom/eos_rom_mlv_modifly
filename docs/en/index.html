Readable Thai text with combining marks and language switching. Familiar technical names such as Focus Peaking and Histogram stay recognizable.

Tools, thoughtfully grouped

Separate categories for shooting, focus, video and games. Camera information and shutter counts are shown when their properties are actually available.

Before you begin

A few things to know.

Is this official Canon firmware?

No. This is an independent fork of Magic Lantern, which runs alongside Canon's software. It is not a Canon firmware updater and is not endorsed by Canon or the Magic Lantern team.

Can I download and install a stable version now?

No general-use stable release is announced. v3r2 is experimental and awaits hardware testing and a dependency-source review. If studying test builds in the repository, read all limitations and installation instructions. Do not use them on other cameras or firmware versions.

Which modules do Pong and Sokoban use?

Both are Lua scripts using the lua module, not separate modules named after each game. Arkanoid uses the arkanoid module. Read the game guide first. v3r2 gameplay has not been verified on camera hardware.

Does this website collect information or accept payments?

This site has no data-collection forms, accounts, analytics trackers or payment processing. If hosted on GitHub Pages, access data is processed under GitHub's privacy policy. External services have their own policies.
