Why we started

An old camera.
A reason to learn together.

Starting with a Thai menu,
and a wish to share with fellow photographers.

This project grew out of our appreciation for Magic Lantern and the community whose work has brought so many capabilities to older cameras. We want to build on that work with a Thai-language interface, making these tools easier to understand and accessible to more people in Thailand.

Another aim is simple: larger menu text that is more comfortable to read. We want menu names and settings to be easier to see while using the camera. These are the everyday improvements we hope to make, step by step, through practical experience and feedback.

We also hope this project encourages more Thai people to explore software development for photography: learning how camera tools work, where to start, and how they might adapt or develop tools for their own needs.

Along the way, we want to make open source more familiar in Thailand by sharing source code and what we learn, and crediting the people whose work we build on. Reviewing a translation, reporting a problem, offering an idea or trying a little code can all be ways to learn together. You are welcome to join us.

Before you begin

A few things to know.

Is this official Canon firmware?

No. This is an independent fork of Magic Lantern, which runs alongside Canon's software. It is not a Canon firmware updater and is not endorsed by Canon or the Magic Lantern team.

Can I download and install a stable version now?

The v3r5 First-install kit includes the original ML installer and current menu; no separate prior ML package is required. Existing ML users can choose Update instead. It remains Experimental with first-install hardware behavior unverified. Read the instructions and verify SHA256SUMS before use.

Which modules do Pong and Sokoban use?

Both are Lua scripts using the lua module, not separate modules named after each game. Arkanoid uses the arkanoid module. Read the game guide first. v3r2 gameplay has not been verified on camera hardware.

Does this website collect information or accept payments?

This site has no data-collection forms, accounts, analytics trackers or payment processing. If hosted on GitHub Pages, access data is processed under GitHub's privacy policy. External services have their own policies.
