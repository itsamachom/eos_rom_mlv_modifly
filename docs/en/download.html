Update an existing ML installation

  1. Back up the card, including the existing autoexec.bin and ML/ directory.
  2. Turn off the camera, use a card reader and extract UPDATE.zip on the computer.
  3. Replace autoexec.bin and the entire ML/ directory at the card root, without adding another folder layer.
  4. Turn on the camera and check Setup (+) → Version: Thai-Menu v3r4.
  5. Do not run Firmware Update again for this menu update. Read INSTALL_EN.md inside the ZIP first.

No ML on the camera yet? This package is not a first-install kit and has no FIR. It does not replace the ML installation procedure; first-install testing is not claimed.
