Thai-Menu v3r5 — ภาพเมนูจากโค้ด

ภาพจำลองจากตัววาดเมนูจริงบนคอมพิวเตอร์ ไม่ใช่ภาพจับจากกล้อง

ใช้ตำแหน่ง ข้อความไทย และฟอนต์จากโค้ดรุ่นนี้โดยตรง สีใช้พาเลตจำลอง ค่า “ยังใช้งานไม่ได้ / Unavailable” ใช้แทนค่าที่ต้องอ่านจากกล้อง ไม่ใช่ข้อผิดพลาดของกล้อง รุ่นกล้องและ Canon firmware เป็นค่าตัวอย่างของรุ่นเป้าหมาย ไม่ได้อ่านจากกล้องของคุณ

ชุดนี้ครอบคลุมรายการ 44 เมนูใน Photo UI และหน้าตัวเลือกที่กำหนดไว้ในโค้ดสำหรับ 600D โมดูลเสริมและเกมแสดงสถานะยังไม่โหลด ไม่รวมหน้าต่าง Classic/ตัวแก้ไขเดิม/รายการโมดูล/หน้าจอเกม และไม่จำลองการซ่อนแถวหรือคำเตือนตามสถานะกล้องจริง
