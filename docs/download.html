วิธีอัปเดตสำหรับกล้องที่มี ML แล้ว

  1. สำรองข้อมูลในการ์ด รวมถึง autoexec.bin และ ML/ เดิม
  2. ปิดกล้อง ใช้ card reader และแตกไฟล์ UPDATE.zip บนคอมพิวเตอร์
  3. นำ autoexec.bin กับโฟลเดอร์ ML/ ทั้งชุดไปแทนที่ที่รากการ์ด อย่าเพิ่มโฟลเดอร์ซ้อน
  4. เปิดกล้อง ตรวจ + → เวอร์ชั่น ว่าเป็น Thai-Menu v3r4
  5. ไม่เรียก Firmware Update ซ้ำเพื่ออัปเดตเมนู อ่าน INSTALL_TH.md ที่แนบใน ZIP ก่อนใช้

ยังไม่มี ML บนกล้อง? แพ็กเกจนี้ไม่ใช่ตัวติดตั้งครั้งแรกและไม่มี FIR กรุณาอย่าใช้แทนขั้นตอนติดตั้ง ML รุ่นนี้ยังไม่มีผลทดสอบการติดตั้งครั้งแรกใหม่
