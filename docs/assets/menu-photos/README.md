# Camera-menu photos

Six photographs supplied by the project creator in `Picture.zip`, for use on
this project website. Credit: Online2easy / the project creator.

No additional reuse license for the photographs is stated here. The website's
source-code license is not a blanket license for these photographs or the
third-party interface depicted in them. Upstream Magic Lantern credits remain
in the website and repository notices.

Public JPEGs retain the original 2000 × 1268 dimensions, colors and decoded
pixels. Non-rendering metadata, including EXIF/GPS and device information, was
removed without re-encoding or cropping. Originals remain outside the repository.
Asset hashes and input filenames are recorded in
`website-content/menu-photos.json` at the repository root; no location metadata
is included in that record.

The pictured build version was not supplied. These photos document visible menu
rendering and do not establish that every function or installation procedure
has passed testing.
